## ADDED Requirements

### Requirement: 缓存电影海报

系统 SHALL 在电影库网格及详情按当前译文的缓存路径显示 TMDB 海报，不重新抓取电影数据。

#### Scenario: 路径存在

- **WHEN** 缓存中有合法的海报文件路径
- **THEN** 浏览器从固定 TMDB 图片域加载对应海报

#### Scenario: 海报不可用

- **WHEN** 路径缺失、不合法或图片加载失败
- **THEN** 原位显示占位提示并保持电影可访问

### Requirement: 受邀管理员访问

系统 SHALL 只向受邀管理员提供后台会话，并在服务端保护所有后台页面和管理 API；系统不提供公开注册。

#### Scenario: 受邀账户登录

- **WHEN** 通过 GitHub OAuth 登录的账户 ID 在管理员白名单中
- **THEN** 系统允许该账户访问后台

#### Scenario: 已有会话时 OAuth 回调返回错误

- **WHEN** OAuth 回调因重复访问或其他原因返回登录错误，且浏览器已有通过当前白名单校验的有效管理员会话
- **THEN** 系统从登录页返回固定后台首页，不为失败的回调签发新会话或写入成功审计，也不放宽 `state` 或 PKCE 校验

#### Scenario: 无有效会话时 OAuth 回调返回错误

- **WHEN** OAuth 回调返回登录错误，且浏览器没有有效受邀管理员会话
- **THEN** 系统保留错误提示与可用时的重试入口，不返回管理数据

#### Scenario: 未受邀或持外部密钥访问

- **WHEN** 未受邀账户或仅持 VidAll API Key 的调用方尝试访问后台
- **THEN** 系统拒绝访问且不返回管理数据，后台页面与 API 文档转至登录页，内部管理 API 和 OpenAPI JSON 返回未授权状态

#### Scenario: 账户从邀请名单移除

- **WHEN** 管理员邀请名单变更已生效，且被移除账户持旧会话访问后台
- **THEN** 系统按当前名单复核并拒绝访问，不等待旧会话过期

#### Scenario: 记录 GitHub 登录准入判定

- **WHEN** GitHub 回调提供可验证的账户 ID，系统判定其受邀或未受邀
- **THEN** 系统记录账户 ID、时间、固定动作和判定结果，不记录 OAuth 或会话秘密；无法写入审计时不签发会话

### Requirement: 只读电影浏览与审计

系统 SHALL 支持按 TMDB ID 或片名查询缓存，并按语言和缓存状态筛选；详情展示抓取时间、过期时间和下架状态。系统 SHALL 记录凭据变更、任务重跑和外部密钥撤销等关键动作，不记录秘密。

#### Scenario: 查询已缓存的电影

- **WHEN** 管理员按已缓存电影的 TMDB ID 查询
- **THEN** 后台展示数据库记录和其缓存状态，不触发 TMDB 回源

#### Scenario: 读取已过期、下架或缺失译文

- **WHEN** 管理员查看仍保存在库中的过期或下架电影，或切换至一个未缓存的译文语言
- **THEN** 后台区分已过期、超出保留期、已下架和译文未缓存；显示真实保存时间，不抓取上游也不改写缓存

#### Scenario: 数据库不可用

- **WHEN** 管理员访问电影列表或详情且数据库查询失败
- **THEN** 后台提示暂时无法读库，不将故障显示为无匹配记录，也不以演示数据替代

#### Scenario: 变更敏感配置

- **WHEN** 管理员撤销外部应用凭据
- **THEN** 审计记录包含操作者、时间、动作和结果，不包含密钥
